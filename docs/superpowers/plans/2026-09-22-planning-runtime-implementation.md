# Planning Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compile resolved business intents into a validated task DAG that binds runtime Tool results into later steps and executes with deterministic branching, idempotency, and bounded replanning.

**Architecture:** Planning is split into immutable contracts, intent-specific compilers, a whitelist result resolver, a scheduler, and a Tool executor. The LLM never supplies trusted resource IDs; a later step receives them only through typed bindings from successful earlier steps.

**Tech Stack:** Python 3.12, Pydantic 2.10+, LangGraph 1.2.12, existing Person/Relation Tools, `unittest`.

**Spec:** `docs/superpowers/specs/2026-09-22-enterprise-intent-routing-design.md`

## Global Constraints

- Plan 1 must be complete and its intent contracts are immutable inputs to this plan.
- Result bindings may access only fields declared by each Tool contract.
- Read steps may run in a parallel batch; write steps remain serial in this version.
- Every write step has a deterministic idempotency key generated by code.
- Replanning is limited to two attempts and a plan signature cannot repeat.
- A failed step prevents dependent steps from running.
- The old `plan_tasks` and `execute_tools` nodes remain active until Plan 3 integration.

## Review Focus

- A cycle such as `a → b → a` must be rejected before execution; Task 1 pins this.
- A binding path outside the Tool output schema must fail without evaluating arbitrary code; Task 3 pins this.
- Zero, one, and multiple `find_person` candidates must route differently; Task 4 pins this.
- A retry of the same write step must reuse the same idempotency key; Task 2 pins this.
- A failed prerequisite must mark its descendants `SKIPPED` rather than executing them with missing IDs; Task 4 pins this.

```python
class ToolResultCode(str, Enum):
    SUCCESS = "SUCCESS"
    TOOL_NOT_FOUND = "TOOL_NOT_FOUND"
    RESOURCE_NOT_FOUND = "RESOURCE_NOT_FOUND"
    PERSON_NOT_FOUND = "PERSON_NOT_FOUND"
    MULTIPLE_PERSONS_FOUND = "MULTIPLE_PERSONS_FOUND"
    RELATION_NOT_FOUND = "RELATION_NOT_FOUND"
    VALIDATION_ERROR = "VALIDATION_ERROR"
    PERMISSION_DENIED = "PERMISSION_DENIED"
    CONFLICT = "CONFLICT"
    DEPENDENCY_UNAVAILABLE = "DEPENDENCY_UNAVAILABLE"
    TIMEOUT = "TIMEOUT"
    INTERNAL_ERROR = "INTERNAL_ERROR"


class ToolResult(BaseModel):
    model_config = ConfigDict(extra="forbid")
    success: bool
    code: ToolResultCode
    message: str = ""
    data: dict[str, Any] = Field(default_factory=dict)
    retryable: bool = False
    affected_count: int = 0

    @classmethod
    def ok(cls, *, data: dict[str, Any]) -> "ToolResult":
        return cls(success=True, code=ToolResultCode.SUCCESS, data=data)

    @classmethod
    def failure(
        cls,
        code: ToolResultCode,
        message: str,
        *,
        retryable: bool = False,
    ) -> "ToolResult":
        return cls(
            success=False,
            code=code,
            message=message,
            retryable=retryable,
        )


class StepExecution(BaseModel):
    model_config = ConfigDict(extra="forbid")
    step_id: str
    status: StepStatus = StepStatus.PENDING
    attempts: int = Field(default=0, ge=0)
    result: ToolResult | None = None
    started_at: datetime | None = None
    finished_at: datetime | None = None
    skip_reason: str | None = None
```

```python
@dataclass(frozen=True, slots=True)
class ToolContract:
    name: str
    bindable_outputs: frozenset[str]


def read_declared_path(payload: dict[str, Any], path: str) -> Any:
    current: Any = payload
    for segment in path.split("."):
        if not isinstance(current, dict) or segment not in current:
            raise BindingResolutionError("RESULT_BINDING_FAILED", path)
        current = current[segment]
    return current
```

```python
class ToolRegistration:
    function: Callable[..., dict | ToolResult]

    registration = TOOL_REGISTRY.get(tool_name)

        return ToolResult.failure("TOOL_NOT_FOUND", f"Unknown tool: {tool_name}")
    try:
```
