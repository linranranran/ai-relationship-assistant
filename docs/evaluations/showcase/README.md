# 冻结评测的公开证据

本目录用于解释“测了什么、怎么测、结果有哪些限制”，全部业务人物与聊天均为虚构。实验日期为2026-10-14，产品当时仍使用早期名称；2026-10-21的品牌整理未重新调用模型。

## 阅读顺序

1. [方案与评分口径](../../评测文档/AI%20人际关系助手评测方案.md)。
2. [统计快照](summary.json)：模型、代码/数据摘要、180次试验与886次模型请求。
3. [独立复评分](scoring-v3-audit.json)：外部状态、故障是否命中、遗漏的硬失败与待审语义。
4. [完整结论](../../评测文档/评测结果与验收结论.md)与[整改记录](../../评测文档/失败案例与整改记录.md)。

## 分层与结果

- 数据集60例，40开发/20保留验收；核心44例按模式/三次重复组成180次图试验。
- 真实模型与真实LangGraph运行，业务/预算/检查点仓储为隔离替身；不能称为180次真实数据库集成。
- 正向准备单结构生成42/45，来源/逐字合法358/358；语义事实支持、建议可用性和完整任务完成率仍待真实人工复核。
- [真实恢复](recovery.json)包含两个进程抢占、提交后崩溃、服务重启后恢复中断、目录版本变化与HTTP预算耗尽；组件/HTTP实验分别标层级。
- [真实性能](performance.json)为4账号并发、8个HTTP/SSE样本，完整回复P95约15.87秒。它不是生产容量认证。

**门禁：NOT_ACCEPTED。** 原规则漏掉了新增额外属性、重复关系和错误地宣称全部完成；关键词出现在否定句也可能误判。v3复评分不覆盖原始分数，完整业务完成率为null。P14六次未命中预设故障，不能声称完成该项容错覆盖。

## 公开范围与复现

本目录只发布三个筛选后的合成原始样例、180次复评分、聚合统计与恢复/性能证据。完整本地日志、数据库COPY备份、源代码运行快照及私人Langfuse项目链接不进入Git。**公开样例不能独立验证全部180次试验的每个原始细节。**

完整数据集在 [scenarios-v2.jsonl](../../评测文档/data/scenarios-v2.jsonl)，评测入口为 [run.py](../../../scripts/evaluation/run.py)。自行运行会产生新的run_id、模型调用与费用，不能预期复现完全相同的文本或指标。方法与参数见[脚本说明](../../../scripts/evaluation/README.md)。

已有完整本地运行目录时，可用 `python -m scripts.evaluation.publish_snapshot` 重新导出本目录；导出本身不调用模型、不连接数据库、不上传。
